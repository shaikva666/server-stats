# Server Performance Stats

This project is a Bash script that displays basic server performance statistics.

## What it shows

- CPU usage
- Memory usage
- Disk usage
- Top 5 processes by CPU usage
- Top 5 processes by memory usage

## How to run

Open the terminal and run:

```bash
chmod +x server-stats.sh
./server-stats.
